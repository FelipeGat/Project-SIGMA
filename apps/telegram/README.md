# apps/telegram

Superfície conversacional do SIGMA via Telegram — permite disparar e acompanhar Missions diretamente de um chat, usando `plugins/telegram` como canal de entrada/saída.

Não planejado para nenhuma camada do [ROADMAP.md](../../ROADMAP.md) ainda — existe como placeholder estrutural desde a Sprint 0.2. Depende de `packages/intent-engine` e `services/gateway` já existirem.
