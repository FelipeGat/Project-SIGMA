# apps/cli

`sigma-cli` — operação do SIGMA por linha de comando: disparar Missions, consultar status, gerenciar Plugins localmente. Previsto em [VISION_2030.md](../../VISION_2030.md) como um dos pontos de entrada da plataforma além de Web/Mobile.

Não planejado para nenhuma camada do [ROADMAP.md](../../ROADMAP.md) ainda — existe como placeholder estrutural desde a Sprint 0.2.
