# apps/admin

Console administrativo do SIGMA — gestão de Tenants/Companies/Workspaces, Users/Roles, Plugins instalados e configuração dos Engines. Distinto de `apps/web` (painel operacional de Missions): este app é a superfície de administração da plataforma em si.

Não planejado para nenhuma camada do [ROADMAP.md](../../ROADMAP.md) ainda — existe como placeholder estrutural desde a Sprint 0.2 porque a necessidade (gerir Tenant/Workspace/Role, ver [MULTITENANCY.md](../../MULTITENANCY.md)) já está identificada, mesmo sem épico definido.
