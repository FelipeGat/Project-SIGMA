**`docker compose down -v` + `build --no-cache` + `up` executado de fato** — ambiente genuinamente limpo, não reaproveitando nenhuma imagem, volume ou dado de rodadas anteriores. Os 4 containers (`redis`, `mariadb`, `gateway`, `auth`) subiram e ficaram saudáveis. Pilha derrubada (`down -v`) ao final, sem deixar nada residente.

## Coverage

**Ainda não medida** — nenhuma ferramenta de coverage (Xdebug/PCOV) disponível no ambiente local (`php -m` confirma ausência de ambas). Mesma pendência registrada desde a Release 2, não resolvida nesta Release — sinalizada explicitamente, não escondida.

## Scenario Validation

- ✅ `docker compose down -v` (remove volumes) → `build --no-cache` (ignora cache de build) → `up` — ambiente genuinamente limpo, não uma repetição da validação da Release 3B.
- ✅ Fluxo `login → workspace → context → logout` completo, do zero, com dado seedado depois do ambiente já limpo — validado via HTTP real.
- ✅ Logout invalida a Session de fato — confirmado via segunda chamada a `/auth/context` retornando `404`.
- ⚠️ **Achado real**: a primeira chamada HTTP ao `auth` num ambiente limpo falhou ao tentar seedar dados diretamente via `docker exec` (schema ainda não existia) — migrations só rodam dentro de `IdentityEngineModule::boot()`, disparado só por uma requisição HTTP real, não por um hook de inicialização do container. Documentado no Decision Log; não corrigido (mudaria comportamento, fora do escopo desta Release).

## Pendências

- Coverage de código ainda não medido.
- `IDENTITY_MODEL.md` ainda descreve `Context` como objeto de mais alto nível (não `Identity`) — divergência já registrada via ADR-0064 desde a Release 3, mantida por princípio (documento histórico não reescrito retroativamente).
- Divergência `autonomy_level_required`/`autonomyCapabilities` (ADR-0068) — reconciliação adiada para o Skill Engine (Release 8).
- `PermissionId` sem uso na Infrastructure — sinalizado desde a Release 3B.
- Migrations rodam na primeira requisição HTTP, não na inicialização do container — característica conhecida, não corrigida nesta Release (ver Decision Log).
- Cinco direções aprovadas mas não implementadas (Workspace/Context em Session, metadata de evento) — ver ADR-0075/ADR-0076, aguardando a próxima vez que `Domain/`/`Application/` do Identity Engine forem tocados com mudança de comportamento real.
