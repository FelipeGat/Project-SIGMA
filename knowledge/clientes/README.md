# Knowledge / Clientes

Contexto qualitativo sobre clientes relevantes do ecossistema Alfa — o que não está (e não deveria estar) no cadastro do Gestor.Alfa: preferências, histórico de relacionamento, sensibilidades, decisores reais por trás do contato formal, particularidades de cada contrato.

## Formato esperado

Um arquivo por cliente relevante (`nome-do-cliente.md`), com seções livres, mas tipicamente incluindo: contexto do relacionamento, decisores, histórico relevante de decisões/negociações, particularidades a considerar em qualquer Mission que envolva este cliente.

Não duplicar dados que já existem estruturados no Gestor.Alfa (razão social, contatos formais, orçamentos) — referenciar pelo identificador do Gestor.Alfa quando necessário, não copiar.
