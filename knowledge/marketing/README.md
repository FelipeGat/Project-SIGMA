# Knowledge / Marketing

Posicionamento de marca, identidade visual (paleta, tipografia, padrões por empresa do grupo), público-alvo por produto, e prova social disponível — o contexto que um Agent de Design (Gemini) precisa para produzir uma peça consistente com o que a empresa já estabeleceu, sem recriar padrão a cada Mission.

## Formato esperado

Um arquivo por empresa/marca (`nome-da-marca.md`) com identidade visual e posicionamento, mais arquivos temáticos como `publico-alvo.md` e `prova-social.md` referenciando onde os materiais (logos, cases) estão armazenados.
