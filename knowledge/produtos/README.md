# Knowledge / Produtos

Catálogo, em linguagem de negócio, dos produtos e serviços oferecidos pela Alfa e pelas empresas do Grupo Soluções — o que cada um resolve, para quem, e como se posiciona frente a alternativas do mercado.

## Formato esperado

Um arquivo por produto/linha de produto (`nome-do-produto.md`): o que é, problema que resolve, público, diferenciais, e — quando relevante — como se relaciona com outros produtos do ecossistema (ex: AlfaControl e o módulo Portal do Cliente).

Não é o catálogo comercial detalhado com preço/SKU (isso vive no Gestor.Alfa/itens_comerciais) — é o contexto que permite a um Agent entender *por que* um produto existe antes de recomendá-lo ou descrevê-lo numa proposta.
