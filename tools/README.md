# tools

Ferramentas de desenvolvimento internas ao monorepo: scripts de scaffolding de novo pacote/serviço/plugin, geração de código a partir de contratos, configuração compartilhada de lint/formatação entre `apps/`, `packages/` e `services/`.

Vazio na Fase Foundation. O primeiro script provável é o gerador do esqueleto de um novo pacote (`Domain/Application/Infrastructure/Presentation`, ver [ARCHITECTURE.md §8](../docs/architecture/ARCHITECTURE.md)), útil a partir do momento em que o segundo Engine começar a ser implementado.
