# packages/sdk

`sigma-sdk` — biblioteca pública para sistemas externos (incluindo os do próprio ecossistema Alfa) integrarem com o SIGMA sem depender de detalhes internos dos Engines: criar Missions, consultar status, assinar eventos. Ver [VISION_2030.md](../../VISION_2030.md).

Não planejado para nenhuma camada específica do [ROADMAP.md](../../ROADMAP.md) ainda — depende de `services/gateway` ter uma API pública estável primeiro.
