# packages/audit-engine

Implementação do Audit Engine: persistência estruturada de `Event` e `Log` com correlação completa (Mission → Subtask → Agent → Skill), e a API de consulta necessária para auditoria de negócio. Distinto de Telemetry (infraestrutural) — ver [TELEMETRY.md](../../TELEMETRY.md) para a diferença entre os dois.
