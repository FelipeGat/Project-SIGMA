# packages/design-system

Componentes visuais e tokens (cor, tipografia, espaçamento, dark mode) compartilhados por `apps/web` e `apps/mobile`, garantindo consistência visual entre as duas interfaces sem duplicar implementação. Ver [ADR-0002](../../docs/adr/0002-estrutura-de-monorepo.md) (razão original de manter web e mobile no mesmo monorepo) e [PLUGIN_SYSTEM.md](../../PLUGIN_SYSTEM.md)/[knowledge/marketing](../../knowledge/marketing/) para a identidade visual de referência.
