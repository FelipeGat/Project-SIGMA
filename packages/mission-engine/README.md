Implementação do Mission Engine: entidade `Mission`, máquina de estados do ciclo de vida (ver [ARCHITECTURE.md §6](../../docs/architecture/ARCHITECTURE.md)), acompanhamento de Subtasks a partir de um Plan já decidido pelo Planner Engine. O agregado raiz do domínio — ver [ADR-0003](../../docs/adr/0003-mission-como-entidade-central.md).

Vazio na Fase Foundation. Camada L4 do [ROADMAP.md](../../ROADMAP.md), depende de `packages/planner-engine`.
