# packages/memory-engine

Implementação do Memory Engine: organiza `Knowledge` (o que se sabe), `Memory` (o que se aprendeu) nos três níveis descritos em [MEMORY_ARCHITECTURE.md](../../MEMORY_ARCHITECTURE.md) — Operational, Project e Long Term — e a custódia dos primeiros Digital Twins ([DIGITAL_TWIN.md](../../DIGITAL_TWIN.md)). Alimentado por eventos Semantic publicados por qualquer Engine (ver [EVENT_MODEL.md](../../EVENT_MODEL.md)), a partir dos que o Identity Engine já publica hoje; primeira fonte real de Knowledge é o conteúdo já existente em [/knowledge](../../knowledge/).
